# ひづけメモ

「明日 グッズ締切」のように打つだけで、日付つきで残せるメモアプリ（PWA）。
下のタブで「日付メモ」「買うもの」「着せかえ（色・フォント・背景画像）」を切り替えられます。
メモも設定も背景画像も、スマホのブラウザの中に保存されます。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（画面・日付の読み取り・保存） |
| `manifest.webmanifest` | ホーム画面に置いたときの名前・アイコン・表示方法 |
| `sw.js` | オフラインでも開けるようにする Service Worker |
| `icon-192.png` など4つの画像 | ホーム画面用のアイコン |

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例：`hizuke-memo`、Public）
2. 「uploading an existing file」から、このフォルダの中のファイル全部（8つ）をドラッグしてアップロードし、Commit
3. リポジトリの **Settings → Pages** を開く
4. 「Build and deployment」の Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
5. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになる

## スマホのホーム画面に置く

- **iPhone（Safari）**：URL を開く → 共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**：URL を開く → 右上の「⋮」 → 「ホーム画面に追加」（「アプリをインストール」と出ることもある）

## 注意

- メモはそのスマホのブラウザの中だけに保存されます。ほかの端末とは同期しません。
- iPhone では、ホーム画面から開いたアプリと Safari で開いたページは保存場所が別です。ホーム画面のほうを使い続けてください。
- アプリを削除したり、ブラウザのサイトデータを消したりするとメモも消えます。

## 中身を書き換えたとき

`index.html` を直したら、`sw.js` の先頭にある `VERSION` を `"hizuke-v2"` のように変えてからアップロードしてください。変えないと、スマホに古い版が残ることがあります。反映はアプリを一度閉じて開き直したタイミングです。

## 手元で試す

このフォルダで次を実行して、ブラウザで `http://localhost:8000` を開くと動作確認できます（Service Worker も動きます）。

```
python3 -m http.server 8000
```
